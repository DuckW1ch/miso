# Miso - Duck's Personal Dossier 🦆

> "yumyumyum"

Duck 的個人自我介紹與履歷檔案。
採用暗黑恐怖（Horror）風格與紅黑（Red & Black）配色設計。

## 特色
- 💀 純單一檔案（HTML + CSS + JS），無任何第三方依賴框架
- 🩸 響應式設計（RWD），手機與電腦皆能完美瀏覽
- 🔪 捲動淡入動畫（IntersectionObserver）
- 🎮 核心身分報告、三大興趣（Play Video Games、Cook、Draw）與專長（Cook）
- 🥩 互動彩蛋（獻祭餵食與音效合成）

## 使用方式
直接使用瀏覽器開啟 `index.html` 即可預覽。
